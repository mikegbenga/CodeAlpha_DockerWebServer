NGINX web server, running in Docker

This page is served by a hardened, non-root NGINX container with a health check, resource limits, a read-only filesystem, structured logs and Prometheus metrics.

Containerized

Built from nginx-unprivileged:alpine. The image is small and pinned, and NGINX runs as UID 101.

Self-healing

HEALTHCHECK probes /healthz every 15 s and the restart policy brings the container back.

Observable

JSON access logs go to docker logs, and stub_status is exported to Prometheus.

Hardened

Read-only root FS, cap_drop: ALL, no-new-privileges, security headers, rate limiting.
